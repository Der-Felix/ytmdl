# Security Policy

## Supported Versions

Security updates are provided for the latest stable release line of YTMDL.

| Version | Supported          |
| ------- | ------------------ |
| 0.16.x  | :white_check_mark: |
| 0.15.x  | :white_check_mark: |
| < 0.15  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in YTMDL, please report it privately and responsibly. **Do not open a public GitHub issue for vulnerabilities involving authentication bypass, remote code execution, secret leakage, or sensitive data exposure.**

### Reporting Method

Please use **GitHub Private Vulnerability Reporting** via the **Security** tab -> **Report a vulnerability** on the official GitHub repository.

This ensures that the report is encrypted, visible only to project maintainers, and allows for a coordinated disclosure process with an advisory and patch release prior to public announcement.

### What to Include

Please provide:
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept.
- Affected component(s) (Backend, Frontend, Auth, Streaming, etc.) and version information.

### Response Timeline

Reports will be acknowledged within 48 hours, with updates provided as the issue is investigated and remediated.
