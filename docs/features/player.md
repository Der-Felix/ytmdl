# Integrated Web Player

YTMDL features a full-featured, in-browser HTML5 audio player designed for seamless music listening without external desktop applications.

## Player Capabilities

- **Gapless Playback & Crossfade:** Web Audio API engine supporting smooth transitions or crossfades between consecutive tracks.
- **Graphic Equalizer & Parametric DSP:** 10-band graphic equalizer with presets (Rock, Pop, Jazz, Electronic) alongside customizable parametric filters.
- **Audio Visualizer:** Real-time frequency analyzer rendering responsive canvas visualizers.
- **Synchronized Lyrics:** Karaoke-style scrolling lyrics synchronized with playback timestamps.
- **Media Session API:** Native operating system media keys, lock screen playback controls, and track metadata display.
- **Queue Management:** Shuffle, repeat modes (off, all, track), and drag-and-drop queue reordering.
